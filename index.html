01 · Android Team Project 2026

Life Manager

Android 기반 생활 기록 관리 앱입니다. 수면, 공부, 휴대폰 사용, 만보기 데이터를 기록하고 그래프로 확인할 수 있도록 앱 구조와 로컬 DB 흐름을 구현했습니다.

담당 역할

  • Android 생활관리 앱의 주요 기능 구현 참여
  • 수면·공부·휴대폰·만보기 데이터를 관리하는 화면과 흐름 구성
  • Room 기반 로컬 DB와 화면 데이터 연동 기능 구현

구현 기능

  • 수면, 공부, 휴대폰 사용 시간 입력 및 저장
  • 최근 7일 기준 생활 기록 그래프 시각화
  • 주간 평균 계산 및 분석 문구 표시
  • Room Migration을 통한 만보기 데이터 테이블 확장

기술 스택

Android Java Room SQLite XML UI/UX
