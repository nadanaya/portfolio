DentalLink

치과 관리자 웹과 환자 앱을 함께 제공하는 Flutter 기반 팀 프로젝트입니다. Supabase 연동을 바탕으로 환자, 예약, 대기, 알림, 공지 흐름을 실제 병원 운영 방식에 맞게 구현했습니다.

담당 역할

  • 관리자 웹과 환자 앱의 주요 화면 및 상태 관리 구현
  • Provider 기반 데이터 흐름과 Supabase 연동 로직 정리
  • 팀 GitHub 기반 협업, 기능 단위 개발 및 코드 반영

구현 기능

  • 관리자 대시보드, 환자 관리, 수기 예약 등록 화면
  • 진료 대기 목록, 대기 상태 변경, 시술 정보 관리 흐름
  • PIN/QR 인증 발급, 환자 알림함, 공지 및 예약 알림 처리
  • FCM 기반 푸시 알림, 로컬 알림, 중복 알림 캐시 개선

기술 스택

Flutter Dart Supabase Provider Firebase Messaging QR
GitHub 링크 입력
BDAI Team GitHub

  • BDAI 팀 GitHub를 통한 협업 개발

구현 기능

  • 에이전트 실행 결과 저장 또는 후처리 로직
  • 테스트 가능한 모듈 단위 기능 정리

기술 스택

Python LangChain LangGraph LLM

팀 프로젝트를 개인 기여 중심으로 보여주는 방식

DentalLink와 AI Agent System은 팀 저장소를 그대로 제출하기보다, 개인 포트폴리오에서 프로젝트의 목적과 본인이 맡은 역할을 먼저 설명한 뒤 GitHub 링크를 연결하는 방식이 적합합니다. 이렇게 구성하면 팀 프로젝트라는 맥락은 투명하게 유지되고, 평가자는 나영님의 실제 기여 범위를 빠르게 확인할 수 있습니다.

더 자세한 구현 내용은 GitHub와 함께 확인할 수 있습니다.
