핵심 수치

02 Data Pipeline KMA API

Weather Forecast Error

기상청 단기예보와 서울 ASOS 관측 데이터를 결합해 시간대별 강수 예보 오차 여부를 정의하고, 공공 API 기반 데이터셋을 구축한 분석 프로젝트입니다.

핵심 수치

2단기예보 API와 ASOS 관측 API 결합
24h시간대별 강수 예보와 실제 강수 비교
1forecast_error 분류 타깃 생성

문제와 해결

  • 일 단위 강수량만으로는 시간대별 예보 정확도를 검증하기 어렵다는 문제를 정의했습니다.
  • 단기예보의 강수 여부와 ASOS 시간 관측의 실제 강수 여부를 같은 시간 기준으로 맞춰 타깃을 생성했습니다.
  • `forecast_rain != actual_rain` 기준으로 예보 오차 라벨을 만들고, 후속 분류 모델링이 가능한 데이터셋으로 정리했습니다.

기술 스택

Python Pandas Public API Data Validation Classification Target
