01 · Team Project 2026.03 ~ 2026.06

DentalLink

치과 관리자 웹과 환자 앱을 함께 제공하는 Flutter 기반 팀 프로젝트입니다. Supabase와 PostgreSQL을 바탕으로 환자, 예약, 대기열, 공지사항 데이터를 실제 병원 운영 흐름에 맞게 연동했습니다.

분석 관점

  • 문제 정의: 병원 운영에서 예약, 대기, 공지 데이터가 분리되어 실시간 상태 파악이 어려움
  • 분석 지표: 예약 현황, 대기 순번, 상태 변경 이력, 공지 노출 여부
  • 개선 액션: 관리자 화면과 환자 앱이 같은 기준의 최신 상태를 보도록 데이터 조회 흐름 정리

담당 역할

  • Supabase(PostgreSQL) 기반 데이터 구조 설계 및 연동
  • 환자·예약·대기열·공지사항 데이터 처리 기능 구현
  • 관리자 웹 대기 관리 및 공지 관리 기능 개발 지원
  • Flutter와 Supabase 간 데이터 조회·상태 변경 로직 구현
  • Git/GitHub 기반 기능 브랜치 관리 및 협업

구현 기능

  • 예약 및 대기 현황 조회
  • 대기 상태 변경과 순번 자동 조정
  • 환자 PIN 인증 및 데이터 조회
  • 공지사항 등록·수정·조회
  • 데이터 누락 및 API 오류 예외 처리

기술 스택

Flutter Dart Supabase PostgreSQL Provider REST API

분석 관점

  • 문제 정의: 회의록, 일정, 업무 진행 데이터가 흩어져 프로젝트 상태 판단이 늦어짐

구현 기능

  • 업무 진행률과 팀원 기여도 분석
  • 리스크 감지 및 프로젝트 종료 리포트 생성

기술 스택

Life Manager

분석 관점

  • 문제 정의: 생활 기록을 저장만 하면 사용자가 패턴을 이해하기 어려움
  • 분석 지표: 최근 7일 공부 시간, 수면 시간, 휴대폰 사용 시간, 주간 평균
  • 개선 액션: 날짜 기준 데이터를 정리해 그래프와 분석 문구로 행동 변화를 확인할 수 있게 구성

담당 역할

  • Android 생활관리 앱의 주요 기능 구현 참여
  • 수면·공부·휴대폰·만보기 데이터를 관리하는 화면과 흐름 구성
  • Room 기반 로컬 DB와 화면 데이터 연동 기능 구현

구현 기능

  • 수면, 공부, 휴대폰 사용 시간 입력 및 저장
  • 최근 7일 기준 생활 기록 그래프 시각화
