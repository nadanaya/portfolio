# Figma Plugin

Figma 작업 흐름을 보조하기 위한 개인 플러그인 프로젝트입니다. 반복 작업을 줄이고 플러그인 UI와 Figma 캔버스 간 메시지 흐름을 구현했습니다.

## Project Type

Personal Project

## My Contribution

- 개인 저장소 기반 플러그인 기능 기획 및 구현
- Figma Plugin API 기반 UI와 명령 처리 개발
- 사용자 작업 흐름을 고려한 인터랙션 개선

## Main Features

- 선택된 레이어 또는 디자인 요소 분석
- 반복 작업 자동화 및 결과 적용
- 플러그인 UI와 Figma 캔버스 간 메시지 처리

## Tech Stack

- Figma Plugin API
- TypeScript
- HTML
- CSS
