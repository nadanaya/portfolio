DentalLink

치과 운영 과정에서 발생하는 환자, 예약, 대기열, 공지, 광고 데이터를 모바일 앱과 Supabase로 연결한 캡스톤 팀 프로젝트입니다. 관리자 웹 화면의 데이터 연동과 환자 앱의 AI 상담 기능을 직접 구현했습니다.

도메인

병원 예약, 환자 관리, 대기열, 공지·광고 관리, 환자용 AI 상담을 하나의 흐름으로 관리

데이터 모델

환자, 예약, 대기 상태, 공지, 광고, 알림 설정을 Supabase(PostgreSQL) 기반으로 구성

관리자 웹 연동

예약·대기열·광고·공지·알림·환자 관리 등 관리자 화면 8개를 Supabase 서비스·Provider 계층에 연결(17커밋)

환자 앱 AI 상담

Groq API와 로컬 Ollama(tinyllama)를 함께 붙인 AI 상담 기능, PIN 로그인, 예약 캘린더 화면 구현(5커밋)

수동 검증

예약 조회, 대기 상태 확인, 공지 노출, AI 상담 응답 흐름을 앱 화면에서 확인(자동화 테스트는 아직 없음)

개선 예정

RLS 정책, 권한별 접근 제어, 예약 충돌 방지, 위젯/서비스 테스트 추가, main 브랜치로의 통합

전체 시스템

Flutter 앱 + Supabase로 팀이 함께 만든 치과 예약·관리 서비스입니다. 팀 작업은 기능별 브랜치에서 진행되어 main에는 아직 통합되지 않았습니다.

내 기여·검증 범위

관리자 웹 8개 화면의 Supabase 연동(web2 브랜치)과 환자 앱 AI 상담·PIN 로그인(app_dev2 브랜치)을 구현했습니다. 예약·대기·공지 로직은 팀원과 함께 만들었습니다.
